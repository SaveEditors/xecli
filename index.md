# XeCLI

XeCLI is a terminal-first Xbox 360 RGH/JTAG toolkit for live console work with XBDM, JRPC2, FTP, XEX dumping, memory inspection, module control, screenshot capture, Ghidra headless automation, and Games on Demand conversion.

The repository and product name are `XeCLI`. The installed terminal command is `rgh`.
