# Wiki Source

This directory contains the maintained Markdown source for the public XeCLI GitHub wiki.

- Live wiki: [https://github.com/SaveEditors/xecli/wiki](https://github.com/SaveEditors/xecli/wiki)
- Wiki home: [Home](Home.md)
- Release history and current highlights: [Releases](Releases.md)

`Home.md`, `_Sidebar.md`, and `Releases.md` define the public wiki entry points and should stay aligned with the shipped product surface.
